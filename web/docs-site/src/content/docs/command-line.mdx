## `devpit`

A pit stop for your dev machine.

Devpit frees disk space, fixes stuck ports, and keeps your developer tools up to date, from one terminal menu.

Run it with no arguments to open the app.

```text
devpit [flags]
```

**Flags**

| Flag | Type | Default | What it does |
| --- | --- | --- | --- |
| `--ascii` | bool | `false` | force the plain ASCII icon tier |
| `-h`, `--help` | bool | `false` | help for devpit |
| `-v`, `--version` | bool | `false` | version for devpit |

**Examples**

```powershell
devpit
devpit --ascii
```

- [`clean`](#devpit-clean): Scan and clean dev junk without opening the app (not available yet)

## `devpit share cleanup`

Remove a share that an earlier Devpit left behind.

If Devpit or the PC stopped while a folder was shared, the share, its temporary login and the firewall or network changes may still be there. This removes them. Windows asks for permission once.


## Environment variables

| Variable | What it does |
| --- | --- |
| `DEVPIT_NO_TELEMETRY` | Set to 1 to switch usage stats off, whatever the setting says. |
| `DO_NOT_TRACK` | The common Do Not Track switch. Set to 1 to switch usage stats off. |
| `DEVPIT_NO_UPDATE_CHECK` | Set to 1 to skip the once-a-day check for a newer Devpit. |
| `DEVPIT_CONFIG_DIR` | Use this folder for config.toml instead of %APPDATA%\devpit. |
| `DEVPIT_CACHE_DIR` | Use this folder for caches and logs instead of %LOCALAPPDATA%\devpit. |
| `DEVPIT_REDUCED_MOTION` | Turn off spinners and other movement in the app. |
