## `devpit`

A pit stop for your dev machine.

Devpit is a toolkit for developers on Windows: the right account in every folder, disk space back, stuck ports freed, tools updated and big folders moved between PCs, from one menu.

Run it with no arguments to open the app.

For scripts and AI agents: every read command takes --json and never asks anything. A command that would change something asks first at a terminal (default No); with nobody at a terminal it changes nothing and exits 3 unless --yes is given, and --yes is only for after the user agreed. Agents: run `devpit agent install` for a skill with these rules.

Exit codes:
- 0: done
- 1: failed
- 2: wrong usage
- 3: needs --yes: it would change something and nobody agreed
- 4: verify found a mismatch

```text
devpit [flags]
```

## `devpit accounts verify`

Check, for every tool, that the expected account is the one in use.

For every installed tool, compares the account Devpit expects in this folder with what the tool says (Git and GitHub pushes offline, the others by asking the tool who is signed in), and lists every problem with its fix. Exit code 4 when anything does not match.

By default only the account used in this folder is asked. --all asks every account; a check that can sign an idle account out (Claude Code) is skipped, with the reason, unless you agree at the prompt or pass --yes after the user agreed.

--json shape: \{folder, mismatch, checks: [\{tool, account, here, expected, actual: \{state, email, login, name, org, plan, method, note\}, says, how, status, notes, docs\}], problems: [\{kind, tool, message, fix, docs\}], skipped\}. status is ok, mismatch, info, not installed or error.

## Environment variables

| Variable | What it does |
| --- | --- |
| `DEVPIT_NO_TELEMETRY` | Set to 1 to switch usage stats off, whatever the setting says. |
| `DO_NOT_TRACK` | The common Do Not Track switch. Set to 1 to switch usage stats off. |
| `DEVPIT_NO_UPDATE_CHECK` | Set to 1 to skip the once-a-day check for a newer Devpit. |
| `DEVPIT_CONFIG_DIR` | Use this folder for config.toml instead of %APPDATA%\devpit. |
| `DEVPIT_CACHE_DIR` | Use this folder for caches and logs instead of %LOCALAPPDATA%\devpit. |
| `DEVPIT_ACCOUNTS_DIR` | Use this folder for the account folders Devpit creates instead of %USERPROFILE%\.devpit\accounts. Devpit's Git rule files move with it, to a git folder beside it. Meant for tests and portable installs. |
| `DEVPIT_SHIM_DIR` | Use this folder for the account shims (claude.exe, gh.exe and the rest) instead of %LOCALAPPDATA%\Programs\devpit\shims. While it is set, Devpit does not change your user PATH, so put that folder first on PATH yourself. Meant for tests and portable installs. |
| `DEVPIT_REDUCED_MOTION` | Turn off spinners and other movement in the app. |
