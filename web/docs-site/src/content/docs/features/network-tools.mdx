Three small tools for checking your connection.
Open them from the main menu with <kbd>5</kbd>, or choose **Network Tools**.

<Shot name="network-menu" />

## My IP addresses

1. Choose **My IP addresses**.
2. Devpit lists your **local interfaces**, for example Wi-Fi or Ethernet, with their IPv4 and IPv6 addresses. Interfaces that are down, and the loopback address, are left out.
3. Under **Public IP** it shows the address the internet sees. It says "Looking up…" first, and "Offline" if it cannot reach a lookup service.

<Shot name="network-ip" />

The local list appears at once.
The public address takes a moment because Devpit has to ask a website for it.
That is the only part of this screen that uses the internet.

Use the local address when another PC on your Wi-Fi needs to reach yours.
Use the public address when you need to tell a service where you connect from.

## Ping a host

1. Choose **Ping a host**.
2. Type a host name or IP address, for example `github.com`. Leave it empty to use `1.1.1.1`.
3. Press <kbd>Enter</kbd>.
4. The replies stream in as they arrive. After four requests you see a summary: packets sent and received, and the minimum, average and maximum time.

<Shot name="network-ping" />

A reply time of a few milliseconds means a healthy connection.
"Request timed out" on every line means nothing came back.
If a host does not answer but other hosts do, that host may block ping.

## Flush DNS cache

1. Choose **Flush DNS cache**.
2. Read the question: "Flush the DNS resolver cache?" It clears cached lookups. Nothing else on your PC changes. The default answer is **No**.
3. Press <kbd>y</kbd>.
4. Devpit runs `ipconfig /flushdns` and shows its answer, for example "Successfully flushed the DNS Resolver Cache."

Flush the DNS cache when a website moved to a new address and your PC still goes to the old one.

:::note
On some PCs Windows only allows this command from a terminal opened as administrator.
If Devpit shows an error, open a terminal as administrator, run `devpit`, and try again.
:::

## Keys

| Key | What it does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move in the menu |
| <kbd>Enter</kbd> | Open a tool, send the ping, or go back when it is done |
| <kbd>y</kbd> / <kbd>n</kbd> | Answer the flush question (No is the default) |
| <kbd>Esc</kbd> | Go back |

See [Keyboard and mouse](/docs/keyboard-and-mouse) for every key.

## Privacy

These tools run on your PC.
Devpit sends nothing about you to its own server.
The public IP lookup is a normal web request to a lookup service, and only happens when you open that screen.
See [Safety and privacy](/docs/safety-and-privacy) for everything Devpit connects to.
