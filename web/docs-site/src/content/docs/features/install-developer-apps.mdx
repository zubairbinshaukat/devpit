Setting up a new PC means installing the same tools again.
Devpit has a short list of common developer tools.
You tick what you want, and it installs them one after another.

Open it from the main menu: press <kbd>4</kbd> for **Install & Update**, then <kbd>1</kbd> for **Install developer apps**.

<Shot name="apps-menu" />

## What is in the list

There are 26 apps in nine groups.

| Group | Apps |
| --- | --- |
| Runtimes | Node.js LTS, Python, Go, Rust (via rustup), .NET SDK, Eclipse Temurin JDK |
| Editors | Visual Studio Code, Notepad++ |
| Terminals & Shell | Windows Terminal, PowerShell 7, oh-my-posh, starship |
| VCS | Git, GitHub CLI |
| Containers | Docker Desktop |
| Package Managers | pnpm, Yarn, Bun |
| CLI Tools | ripgrep, fd, fzf, jq, bat, 7-Zip, lazygit |
| Fonts | Cascadia Code |

Each app shows a one-line description.

## Install apps

1. On the main menu press <kbd>4</kbd>, then <kbd>1</kbd>.
2. Wait a moment while Devpit checks which tools you already have.
3. Move with <kbd>↑</kbd> <kbd>↓</kbd> and press <kbd>Space</kbd> to tick the apps you want.

   <Shot name="install-list" />

4. Press <kbd>Enter</kbd>.
5. Read the question, for example "Install 3 app(s)?". It shows the package manager and the exact command for each app. The default answer is **No**.
6. Press <kbd>y</kbd> to start.
7. Watch the progress. Each app is one live row with a spinner, a progress bar when the manager reports one, and the last thing the installer said.

   <Shot name="install-running" />

8. When it ends you see a summary. Press <kbd>Enter</kbd> to finish.

## Which package manager is used

Devpit uses one manager per run:

| Setting | What Devpit does |
| --- | --- |
| auto (default) | Picks Scoop if it is installed, then winget, then Chocolatey |
| scoop, winget or choco | Uses the one you choose in [Settings](/docs/features/settings) |

The commands Devpit runs are these, with the package name filled in:

```powershell
scoop install <app>
winget install --id <Publisher.Id> -e --accept-source-agreements --accept-package-agreements
choco install <app> -y
```

Some apps are greyed out:

- **installed** means Devpit already found the app on your PATH.
- **not available via …** means the app has no verified package name for the manager in use.

## Admin rights

- **Scoop** installs for your user and needs no admin.
- **winget** may show a Windows prompt for some packages. Devpit tells you on the confirmation screen.
- **Chocolatey** always needs admin. Devpit asks once for the whole run, so ten apps are one prompt. If you say no, those apps are marked "skipped (needs admin)", not failed.

## Keys

| Key | What it does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move |
| <kbd>Space</kbd> | Tick or untick an app |
| <kbd>Enter</kbd> | Install the ticked apps |
| <kbd>y</kbd> / <kbd>n</kbd> | Answer the question (No is the default) |
| <kbd>l</kbd> | Show or hide the full log while installing |
| <kbd>s</kbd> (twice) | Skip the app that is installing now. Press it again within 5 seconds to confirm. The summary shows how to install it later |
| <kbd>Esc</kbd> | Stop. The app in flight is cut short and the rest are skipped |

You can also click a row to tick it.
See [Keyboard and mouse](/docs/keyboard-and-mouse).

## If an install fails

The summary lists each app that failed or was skipped, with a reason.
Press <kbd>l</kbd> to read the full output.
Run the command from the confirmation screen yourself to see the manager's own message.

## After installing

Open a new terminal window so it sees the new PATH.
To keep everything current, use [Update everything](/docs/features/update-everything).
To set your Git name and email next, or a different one per folder, see [Git and GitHub accounts](/docs/features/accounts-git-and-github).
