Devpit is made for the keyboard, and the mouse works too.
Press <kbd>?</kbd> on any screen to see the keys for that screen.

The footer at the bottom of the window always shows the keys that work right now.

## Keys that work everywhere

| Key | What it does |
| --- | --- |
| <kbd>?</kbd> | Show or hide the shortcuts for this screen |
| <kbd>Esc</kbd> | Go back one screen. While a scan, delete, install or update is running, it stops the work instead |
| <kbd>Tab</kbd> | Go to the next section on the tab bar |
| <kbd>Shift</kbd>+<kbd>Tab</kbd> | Go to the previous section |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Quit from anywhere. If work is running, Devpit asks it to stop first |
| <kbd>q</kbd> | Quit, from the main menu only |

On a screen with a form, such as the Share Files sign-in, <kbd>Tab</kbd> moves between fields and does not change section.
While work is running, <kbd>Tab</kbd> does nothing.

## Main menu

| Key | What it does |
| --- | --- |
| <kbd>1</kbd> | Accounts |
| <kbd>2</kbd> | Free Up Disk Space |
| <kbd>3</kbd> | Ports & Network |
| <kbd>4</kbd> | Install & Update |
| <kbd>5</kbd> | Share Files |
| <kbd>6</kbd> | Devpit Settings |

The digits work on the main menu only, so a number you type in a form stays a number.

The tabs in the header are, in the same order: **Accounts**, **Clean**, **Ports & Net**, **Apps**, **Share** and **Settings**.

**Ports & Network** and **Install & Update** each open a small menu with two entries:

| Section | <kbd>1</kbd> | <kbd>2</kbd> |
| --- | --- | --- |
| Ports & Network | Fix stuck ports & apps | Network tools |
| Install & Update | Install developer apps | Update everything |

Press the digit, or move and press <kbd>Enter</kbd>. <kbd>Esc</kbd> goes back to that small menu.

## Menus and lists

These keys work in every menu and pick list.

| Key | What it does |
| --- | --- |
| <kbd>↑</kbd> or <kbd>k</kbd> | Move up |
| <kbd>↓</kbd> or <kbd>j</kbd> | Move down |
| <kbd>Enter</kbd> | Choose the highlighted row |
| <kbd>Space</kbd> | Tick or untick a row, in lists that have tick boxes |
| <kbd>Home</kbd> <kbd>End</kbd> | First or last row, in Settings and on the Accounts tool pages |

Settings and the Accounts tool pages (and the Git page) share one layout: what is true now at the top, then the choices in short groups under headings. The cursor skips the headings. A row ending in `›` opens a screen; a value in `‹ ›` changes in place with <kbd>Enter</kbd>, <kbd>Space</kbd> or <kbd>←</kbd> <kbd>→</kbd>; `●`/`○` is on or off. The highlighted row is explained beside the list (under it on a small window), including what happens when you press <kbd>Enter</kbd>. A row that cannot be used right now stays in the list, greyed, with the reason.

## Questions (the confirm box)

Every question starts on **No**.

| Key | What it does |
| --- | --- |
| <kbd>y</kbd> | Yes |
| <kbd>n</kbd> or <kbd>Esc</kbd> | No |
| <kbd>←</kbd> <kbd>→</kbd> or <kbd>h</kbd> <kbd>l</kbd> | Move between No and Yes |
| <kbd>Enter</kbd> | Choose what is highlighted (No, unless you moved) |

For **Careful** items in Free Up Disk Space you must type a word first: `DELETE`.
Type it exactly, in capital letters, then press <kbd>Enter</kbd>.
<kbd>y</kbd> alone does not work there. <kbd>Esc</kbd> cancels.

## The mouse

The mouse is an extra. The keyboard does everything.

| Action | What it does |
| --- | --- |
| Click a tab in the header | Jump to that section |
| Click a menu row | Open it, like pressing <kbd>Enter</kbd> |
| Hover a row on a menu | Highlights it and shows its description |
| Click a row in Settings or on an Accounts tool page | The first click highlights it; a click on the highlighted row, or on a value, changes or opens it |
| Click a tick box | Ticks or unticks that row, or everything under a project heading |
| Click a fold arrow | Folds or unfolds a group |
| Click a row | Moves the cursor there |
| Scroll wheel | Scrolls menus and lists |

Your terminal must pass mouse events to Devpit.
Windows Terminal does.

## Window size

Devpit needs a window at least **80 columns by 24 rows**.
If it is smaller, Devpit tells you and waits.
Resize the window and it redraws by itself.
