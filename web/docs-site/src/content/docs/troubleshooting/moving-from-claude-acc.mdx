[claude-acc](https://github.com/Nemo-Illusionist/claude-code-account-switcher) binds Claude Code accounts to folders with a PowerShell profile line.
Devpit can take over those accounts and folder links without moving them, so nobody signs in again.
The background is in the blog post [Moving from claude-acc to Devpit without signing in again](/docs/blog/move-from-claude-acc-to-devpit).

## Import

Open **Accounts** in Devpit.
The first time, it says **Found accounts already on this PC** and lists what claude-acc has.
Choose **Use them in Devpit**.

Or from a terminal:

```powershell
devpit claude import --from claude-acc
```

Devpit reads claude-acc's own files (its accounts, folder links and default account), shows what it would add, and after a yes adds them as one change.
`devpit undo` takes the whole import back.
Each claude-acc account stays where it is, under `%USERPROFILE%\.claude-switch\accounts`.
claude-acc's `default` is Devpit's `default`: your normal `%USERPROFILE%\.claude`.

## Retire claude-acc, in this order

The import prints these steps for your PC, with the exact file and line numbers.

1. **Check that Devpit picks the same accounts.** Run `devpit accounts verify`, or open Accounts in a few of the linked folders. Claude Code should show the account claude-acc used there.
2. **Remove claude-acc's line from your PowerShell profile.** Open it with `notepad $PROFILE` and delete the line under `# Claude Code Account Switcher`. Devpit does not edit your profile.
3. **Open a new terminal.** claude-acc's line sets `CLAUDE_CONFIG_DIR` every time a terminal changes folder. A terminal started after the line is gone has no such variable. In an old terminal, Devpit's shim overrides it for `claude`, but close it to be sure.
4. **Remove the program.** Delete claude-acc's `bin` folder inside `.claude-switch`. If you added that folder to PATH yourself, take it out of PATH too.
5. **Keep the account folders.** Do not delete `.claude-switch\accounts` or anything in it while Devpit uses them.

:::danger[Do not run claude-acc remove]
Do not run `claude-acc remove` for an account you imported.
It moves the account's folder to the Recycle Bin, or deletes it outright with `--purge` or when the Recycle Bin cannot take it.
Either way that account is signed out.
:::
