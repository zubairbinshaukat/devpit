**System error 1326: The user name or password is incorrect.** The other PC was found, and it did not accept the sign in.

## What it means

Error 1326 is `ERROR_LOGON_FAILURE`, with the text "The user name or password is incorrect." Compare it with error 53: with 53 Windows cannot find the PC ([system error 53](/docs/troubleshooting/system-error-53-network-path-not-found)). With 1326 it found the PC and the login failed.

## Why it happens

- A typo in the user name or password.
- The account does not exist on the sharing PC, or is not active. Microsoft says an account that is not active cannot access resources on the computer.
- You typed a user name from your own PC, but the sharing PC does not know that name.
- An old connection to the same PC is still open with different credentials. That can also show [error 1219](/docs/troubleshooting/system-error-1219-multiple-connections).

## How Devpit fixes or avoids it

[Share Files](/docs/features/share-files) creates a **temporary login** for each share, so you never have to use your own Windows password.
The sharing PC shows a card with the IP, share name, user name and password.
Type them on the receiving PC exactly as shown.
Stopping the share removes the login, and it is also removed when Devpit quits.
The login expires by itself after 48 hours if nothing removed it.

When Windows refuses a sign-in, Devpit says "The user name or password is wrong" and asks again.
If the user name looks like a Microsoft account e-mail, Devpit tells you to type it as `MicrosoftAccount\you@example.com` and to use the account password, not a PIN.

## The manual fix

1. On the sharing PC, list the accounts. In Command Prompt:

```text
net user
```

Confirm that the user name you use exists. To see details for one account, add its name: `net user username`.

2. On the receiving PC, close File Explorer windows that show the share and disconnect old connections:

```text
net use * /delete
```

3. Open the share again, for example `\\192.168.1.20\share`, and type the user name and password slowly. Copy and paste them if you can.
4. If you reset the password on the sharing PC, use the new one.
5. If you see a message about "unauthenticated guest access", see [the Windows 11 24H2 page](/docs/troubleshooting/guest-access-blocked-windows-11-24h2).
