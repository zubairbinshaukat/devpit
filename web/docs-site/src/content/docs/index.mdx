Devpit is a free terminal app for Windows 10 and 11.
It is small, fast and open source.
These pages show you how to use it, one step at a time.

## Install in one line

Open PowerShell and run:

```powershell
irm https://devpit.zubyr.dev/install | iex
```

Then type `devpit`.
No administrator rights needed.
[Other ways to install](/docs/getting-started) include Scoop and a plain zip file.

## Why you can trust it

<CardGrid>
  <Card title="Nothing goes without a preview" icon="approve-check">
    You always see the list first. Nothing is deleted until you confirm, and the default answer is **No**.
  </Card>
  <Card title="Risk labels on everything" icon="warning">
    **Safe**, **Review** or **Careful**. Careful items need a typed word and go to the Recycle Bin.
  </Card>
  <Card title="Nothing is sent by default" icon="padlock">
    Usage stats are off until you turn them on, and they never include file names or paths.
  </Card>
  <Card title="Open source" icon="github">
    MIT licence. Releases have checksums and a build attestation. Read every rule in the [safety and privacy](/docs/safety-and-privacy) page.
  </Card>
</CardGrid>
