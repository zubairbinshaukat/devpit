1Accounts

The right account, in every folder.

Work repo, side project, a client's Vercel team. Tell Devpit once which account a folder uses, and claude, git, gh, vercel and the rest use it there by themselves.

  • everywhere

    Your default account, used wherever no rule applies.

  • folder rule: C:\Work

    You set it for that folder. The nearest rule wins, one tool at a time.

  • set by the project

    The project picks it, like Convex with .env.local. Devpit shows it.

How a switch goes

  1. Pick a tool. Open Accounts and choose the row you want to change.
  2. Pick an account. One you already use, or sign in through the tool's own login.
  3. Read the preview. Plain words, exactly what changes. The default answer is No.
  4. Verify or undo. v checks each tool, expected against actual. u takes it back.

Or from the command line

PS> devpit claudewhich account is used here, and why
PS> devpit claude use workswitch, after a preview
PS> devpit accounts verifyabout to deploy with the wrong account?
PS> devpit accounts verify --jsonthe same, for scripts and AI agents

Without a terminal to ask in, a change needs --yes, so an AI agent cannot switch an account until you agree.

What it does not do

  • Store or show tokens. Each tool keeps its own login. Devpit's rules file holds names, emails and folders.
  • Touch your repos. Rules live in Devpit's own files, so nothing shows up in git status.
  • Switch editor extensions or desktop apps. Rules apply in terminals, including the VS Code terminal.
  • Switch Convex. Convex picks the account per project; Devpit shows it. Cloudflare support is beta.

Questions

What is Devpit?

Devpit (also searched as Devpit CLI) is a free, open-source toolkit for developers on Windows. One terminal menu puts the right account in every folder, frees disk space, fixes stuck ports, installs and updates your tools and moves big folders between PCs.

Can I use two Claude Code accounts on one PC?

Yes. Add both in Accounts, then choose which one each folder uses. Devpit gives every extra account its own Claude Code config folder (CLAUDE_CONFIG_DIR, the multi-account method Claude Code documents) and sets it only for the claude process started in that folder. Your skills can be shared with the other account and your settings copied over; plugins are installed per account from the same list.

Where are my tokens stored?

Where they already were. Each tool keeps its own login: Claude Code in its account folder, and gh, Vercel, Firebase, Supabase and Wrangler in their own storage. Devpit never stores, shows, copies or uploads a token. Its rules file holds only account names, emails and folder paths.

Does Devpit change my repo?

No. Folder rules live in Devpit's own files in your user profile, never in a repo, so nothing shows up in git status. For Git, Devpit adds marked lines to your global Git config that point at its own rules file, and devpit accounts cleanup removes exactly what it added. Every change is previewed first and can be undone.

Does it work in VS Code and desktop apps?

In terminals, yes: Windows Terminal, PowerShell, cmd, Git Bash and the VS Code terminal, and AI agents or scripts that run the tool from a folder. Editor extensions and desktop apps keep their own login, so Devpit does not switch those.

Which tools can Accounts switch?

Claude Code, Git, GitHub, Vercel, Firebase, Supabase and Cloudflare (beta, folder rules only). Convex is shown and checked but not switched, because Convex picks the account per project.

Who made Devpit?

Devpit is built by Zubair bin Shaukat (zubyr), a software engineer from Lahore, Pakistan. His portfolio is at zubyr.dev and the source is on GitHub under the MIT license.

Is it safe to delete node_modules?

Yes. node_modules comes back when you run npm install (or pnpm or yarn install). Devpit labels it Safe, shows the size first and never deletes anything until you confirm.

How do I fix "port 3000 is already in use" on Windows?

Open Devpit, choose Ports & Network, then Fix stuck ports & apps, and type 3000. Devpit shows which app is holding the port and stops it after you confirm.

How do I copy a big folder between two PCs on the same Wi-Fi?

On the PC that has the files, open Devpit, choose Share Files, then Share a folder, and approve one admin prompt. Devpit shows the IP address, a temporary user name and a password. On the other PC, choose Copy from a shared folder, or type the two lines from the card (net use, then robocopy) if that PC does not have Devpit. You see live progress, and the copy resumes if the network drops. Comparing tools? Read every way to move files between two PCs.

How do I install Devpit?

Two ways, both in PowerShell. The one-liner irm devpit.zubyr.dev/install | iex downloads the latest release, checks its SHA256 and adds it to your PATH. Scoop users add the zubyr bucket and run scoop install devpit, and scoop update keeps it current.

Is Devpit free and safe to install?

Free and open source under the MIT license. Releases are built on GitHub Actions with SHA256 checksums, and the install script is short enough to read in a minute.

Does Devpit collect my data?

Not unless you opt in. Usage stats are off by default and only send totals such as space freed; file names, paths and usernames are never sent. Set DEVPIT_NO_TELEMETRY=1 and nothing is ever sent. Accounts talks to no server of its own: the only network traffic is each tool's own sign-in and who-am-I check.

Does it work on Mac or Linux?

Windows 10 and 11 (x64 and ARM64) today. Linux and macOS are planned.
